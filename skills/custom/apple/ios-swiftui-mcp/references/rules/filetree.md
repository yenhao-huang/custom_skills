# Filetree Rules

Keep `SKILL.md` and `STATE.md` at the skill root. Keep domain guidance in
`references/`, operating rules in `references/rules/`, reusable executable
helpers only in `references/scripts/`, and the state template in
`references/template/STATE.template.md`. Do not add `agents/`, top-level
`scripts/`, README files, generated reports, or cache files.
