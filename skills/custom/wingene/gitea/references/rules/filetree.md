# Filetree Rules

The skill must retain this layout:

```text
gitea/
├── SKILL.md
├── STATE.md
└── references/
    ├── gitea-workflow.md
    ├── rules/
    │   ├── env.md
    │   ├── filetree.md
    │   └── state-rules.md
    └── template/
        └── STATE.template.md
```

Do not add credential files, tokens, generated API responses, or issue
attachments to the skill directory.
