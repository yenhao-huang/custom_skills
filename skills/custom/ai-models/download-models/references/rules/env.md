# Environment Rules

- Primary language: shell commands and Markdown status
- Runtime version: existing `~/Desktop/python-venvs/hf-cli` environment
- Package manager: none during normal downloads
- Frameworks: Hugging Face CLI and tmux
- Service manager: tmux sessions
- Required services: internet access, Hugging Face access when gated, sufficient disk space

Do not install a replacement CLI or environment during a download request. Never expose access tokens.
