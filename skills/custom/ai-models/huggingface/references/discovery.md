# Discovery

Filter candidates by:

- task compatibility;
- license and intended use;
- framework or format such as Transformers, Diffusers, GGUF, or MLX;
- parameter count, quantization, memory, and target hardware;
- revision recency, model-card quality, and maintenance activity;
- known limitations and safety constraints.

Prefer official Hub metadata or model cards. When several candidates fit,
return three with why each fits, hardware expectations, license, and one notable
caveat. Do not rank by downloads unless the user asks for popularity.
