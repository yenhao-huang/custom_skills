# Environment Rules

Required tools: Git, authenticated GitHub access for issues and PRs, OpenSpec
CLI, and the named OpenSpec skills. Check availability and repository identity
before using them; report missing prerequisites accurately.

Use declared project runtimes, lockfiles, package managers, and isolated
environments. Bundled Python/ML setup applies only to matching new projects.
Do not install globally or invent service configuration. Run checks from the
issue worktree, recording commands and relevant versions without secrets.
